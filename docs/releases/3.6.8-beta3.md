# GitHub Desktop Word Wrap 3.6.8-beta3 — BETA

This is an unofficial BETA build of the ZEB-23/desktop fork, based on the merged
word-wrap feature in development. It is not an official GitHub Desktop release.

## Differences from desktop/desktop development

Comparison baseline: desktop/desktop development at
`bebc062caafcf818993b9f53397b976d33484231`, checked on October 14, 2026.
The fork's merged development commit is
`685e875f8d5e7a35db9cd66cdff0c37158f7abbe`.

The development branches differ by the word-wrap feature from
[PR #1](https://github.com/ZEB-23/desktop/pull/1):

- A Word wrap checkbox is available in Diff Options when using unified display.
- Turning it off disables wrapping and allows horizontal scrolling for long lines,
  unbroken tokens, and tabbed text. Turning it on wraps lines to the viewer width.
- Wrapping remains enabled by default, preserving upstream behavior.
- The preference persists in Changes and History and applies to stashed diffs.
  Dialog viewers use the same renderer with their existing local settings ownership.
- Virtualized row heights are recalculated after toggling wrapping or resizing.
- UI regression tests cover the default, toggling, persistence, and display changes.

The release branch adds packaging changes beyond the merged feature:

- Version and changelog updated to `3.6.8-beta3`.
- Separate product name, macOS bundle ID, and Windows installer identity for the
  fork's BETA, so it can be installed alongside the official application. Windows
  command-line launchers target the separately named BETA executable.
- Opt-in unsigned packaging without GitHub's private signing/notarization services
  or downloads of official delta-update packages. Native Node-API dependencies
  use Node.js 24.19.0 headers, avoiding the broken Electron header archive.
- Automatic updates disabled in these builds. Install future fork releases manually
  from [ZEB-23/desktop releases](https://github.com/ZEB-23/desktop/releases).
- A fork-specific native build matrix, release asset collector, checksums, and
  reproducible build metadata. These changes are confined to the release branch;
  the feature commit itself remains independently cherry-pickable or revertible.

The release includes `UPSTREAM-DIFF.patch` for the complete source comparison and
`build-manifest.json` for the exact release commit, upstream baseline, asset sizes,
platforms, and SHA-256 hashes. Private-feed URLs in the upstream lockfile are supplied from the public npm
registry with matching locked checksums. No application dependency versions were
changed.

## Downloads

- macOS: ZIP application bundles for x64 and arm64.
- Windows: EXE and MSI installers, plus full NuGet packages, for x64 and arm64.
- Linux: portable tar.gz application bundles for x64 and arm64. Extract and run
  `desktop`; a desktop environment and Electron system libraries are required.
- GitHub also provides the tagged source archives. Initialize submodules when
  building from a Git checkout.
- Check downloads against `SHA256SUMS` before installation.

These BETA binaries lack trusted distribution signatures. macOS application
bundles use ad-hoc signatures for execution and are not notarized. Windows
SmartScreen and macOS Gatekeeper may require explicit approval to run them.
GitHub sign-in uses the upstream development OAuth client fallback unless a fork
OAuth client is configured at build time. Use this release for testing.

## Validation

The word-wrap feature passed TypeScript checks, lint, focused UI/diff tests, and
Playwright verification in Linux Electron. The release workflow additionally
compiles and packages each platform/architecture on its native runner, records
asset hashes, and publishes only when every matrix build succeeds.
